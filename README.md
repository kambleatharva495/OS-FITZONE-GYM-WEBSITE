# FITZONE Gym Website 💪🔥

A modern and responsive fitness and gym website built using HTML, CSS and JavaScript.

## 🌐 Project Overview

FITZONE is a modern gym website designed to showcase fitness programs, professional trainers, membership plans and customer testimonials.

The website focuses on a bold fitness-inspired design, responsive layouts and interactive user experience.

## ✨ Features

- Responsive design for desktop, tablet and mobile
- Modern navigation bar
- Mobile-friendly menu
- Hero section with call-to-action
- About FITZONE section
- Training programs
- Expert trainer profiles
- Trainer image hover effects
- Membership pricing plans
- Featured Pro membership plan
- Customer testimonials
- Contact / Join FITZONE section
- Smooth scrolling
- Hover animations and orange glow effects
- Responsive mobile layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
